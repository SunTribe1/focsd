# @focsd/charts

`<focsd-chart>`: bar, line, area, stacked, scatter and donut charts drawn as SVG with patterns (not color alone), keyboard-explorable points, a text summary and a data table. Also `<focsd-sparkline>` (a word-sized graphic) and `<focsd-gauge>` (a meter with named bands).

```sh
npm install @focsd/charts @focsd/tokens
```
