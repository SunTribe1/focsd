# @focsd/react

## 1.0.0

### Major Changes

- First public release: 128 accessible, framework-agnostic components, the data grid, a rich text editor, accessible charts, an AI chat kit, an MCP server for AI assistants, WebMCP support for agent-ready sites, a CLI that copies components into your project (`npx focsd add`), design tokens with three themes and three densities, icons (bring your own), localization, TypeScript types and framework typings.

### Patch Changes

- Updated dependencies
  - @focsd/components@1.0.0
  - @focsd/data-grid@1.0.0
  - @focsd/editor@1.0.0
  - @focsd/charts@1.0.0
  - @focsd/ai@1.0.0
