# @focsd/data-grid

`<focsd-data-grid>`: sorting, filtering, quick search, grouping with aggregates, inline editing, column pinning and virtualized rows, accessible by keyboard and screen reader.

```sh
npm install @focsd/data-grid @focsd/tokens
```
