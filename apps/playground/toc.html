Install

Add the package to your project, then import the components you use on each page.

With npm

Run npm install @focsd-dev/components in the folder that holds your package.json.

With a CDN

Load one module from the CDN in a script tag with type="module".

Usage

Write the elements in your HTML as you would any other tag.

Keyboard

Every control is reachable with Tab and shows a focus ring.
