## Accessibility checklist for your grid

- Give every grid a `label` that says what the rows are.
- Keep `rowId` stable, so selection and editing survive sorting and paging.
- Prefer `render` for text and keep cells free of interactive content. A cell holds one focus stop, so put row actions in a toolbar or the row's detail view.
- With `external`, set `loading` while you fetch and keep `row-count` accurate: the counts screen readers hear come from it.
